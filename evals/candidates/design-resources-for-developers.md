## 3. Best audit candidates

1. PagePatch Free Hero Example (https://github.com/l-portet/pagepatch-free-hero): AI-generated before/after hero with 5 explained fixes; a pre-labelled slop/good pair.
2. Magic UI (https://magicui.design/): the effect kit behind many AI landing pages; slop-positive reference.
3. Aceternity UI (https://ui.aceternity.com/): beams/spotlight/aurora tropes; slop-positive reference.
4. shadcn/ui (https://ui.shadcn.com/): the AI default baseline; tests "default, not broken" = neutral.
5. Forge (https://forge.madebyever.com/): current dark SaaS template formula; template baseline.
6. Awwwards (https://www.awwwards.com/): juried good set for false-positive checks.
7. CSS Zen Garden (http://csszengarden.com/): one HTML, 200+ designs; isolates visual choices.
8. Carbon Design System (https://www.carbondesignsystem.com/): rigorous good design-system reference.
9. Bento Grids (https://bentogrids.com/): bento-trope gallery; tests whether Unslop over-flags a pattern vs. its execution.
10. Frontend Mentor (https://www.frontendmentor.io/): same brief, thousands of community builds; spread from slop to good.

## Notes

- 161 targets were picked by hand from 1,251 links. Labels are expectations based on reputation and README text, not observed audits. Templates are neutral and marked "template".
- 5 URLs were spot-checked with WebFetch (Forge, CloneAny, Bento Grids, A1 Gallery, PagePatch repo). All responded, but the tool could not fully confirm Forge or Bento Grids are live. No other URLs were checked; expect some rot in older entries (Httpster 2020 path, SendGrid, Alta, Rizzo, Daemonite has a malformed URL).
- Galleries are collections: audit individual entries sampled from them, not the gallery chrome itself (except for Awwwards/Laws of UX, which are crafted sites).
- "slop" labels here mark trope sources (effect kits, glass/neumorphism generators), useful as positive examples for specific rules.
- Several React/Tailwind kits are near-duplicates (shadcn derivatives); sample 2-3, not all.
